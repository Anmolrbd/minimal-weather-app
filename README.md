# Minimal Weather App

A small, lightweight weather app built with **HTML**, **Tailwind CSS**, and **JavaScript**.  
It fetches live weather data from **OpenWeatherMap API** and shows temperature, humidity, and current conditions in a clean interface.

---

## What it Does

1. Search weather by city 
2. Launch the app by opening **index.html** in your browser  
3. View temperature, humidity, and weather conditions 
4. Works nicely on both desktop and mobile 
5. Minimal design for fast loading

---

## Tech Used

- **HTML** – structure  
- **Tailwind CSS** – styling  
- **JavaScript** – logic & API handling  

---

## How to Run

Run these commands in your terminal:

```bash
git clone https://github.com/YourUsername/minimal-weather-app.git
cd minimal-weather-app
```
Then open **index.html** in any browser.
